# Core Visual Acceptance Gate

The authored core is accepted only when the high-aerial view reads as a coherent historical settlement rather than a procedural demo.

## Required visual properties

- Dense, continuous low-rise urban fabric around the central landmark.
- Irregular settlement silhouette with no obvious circular, square, or grid boundary.
- Narrow, broken, organic alley network. No boulevard-like radial roads.
- Courtyard compounds must vary in footprint, orientation, height, and wall arrangement.
- Sector must read as one connected urban mass from high aerial view.
- Large empty gaps around the central landmark are not acceptable.
- Materials must remain muted earth, clay, basalt, palm-wood tones. Avoid uniform yellow/orange.
- Courtyards and roof variation must remain legible from medium aerial view.
- The core must visually blend into neighboring sectors once they are authored.

## Reject if any of these are obvious

- Repeated identical boxes.
- Concentric rings.
- Straight radial spokes.
- Modern road widths.
- Large empty plazas not historically justified.
- Visible engine-sector boundaries.
- Toy-city proportions.
- Flat single-color terrain.

## Historical rule

The visual reference governs composition and density. Historical project data governs the interpretation, identity, confidence, and placement logic of named landmarks. The visual massing is not presented as exact archaeological parcel reconstruction.

## Review views

Every core iteration must be checked in:

1. High aerial view for silhouette and density.
2. Medium aerial view for neighborhood and alley structure.
3. Low aerial view for building morphology.
4. Mobile view for framing, performance, and interaction.

Do not expand to north/south/east/west production assets until the core passes this gate.
