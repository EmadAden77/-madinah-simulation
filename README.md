# Madinah Simulation

محاكاة تاريخية تفاعلية للمدينة المنورة في الفترة 622–632م، مبنية من الصفر داخل GitHub.

## التقنية

- Next.js 16 + React 19 + TypeScript
- MapLibre GL للملاحة الجغرافية
- WebGL + Three.js للطبقة التاريخية ثلاثية الأبعاد
- Semantic LOD حسب مستوى التكبير
- محاكاة بشر وحيوانات مرئية عند التكبير القريب
- حساب تقريبي لأوقات الصلاة اعتمادًا على الشمس والموقع
- واجهة عربية RTL ومهيأة للهاتف
- GitHub Actions للبناء والنشر على GitHub Pages

## ما تنفذه النسخة الأولى

- خريطة تفاعلية حقيقية بالسحب والتكبير والدوران والميل
- تجمعات عمرانية تاريخية تجريبية
- بساتين نخيل وآبار ومسارات ومناطق زراعية
- طبقة 3D متزامنة جغرافيًا مع MapLibre
- بشر، رعاة، أغنام، ماعز، خيول، إبل وحمير تظهر في مستويات التكبير القريبة
- حركة مستمرة للوكلاء داخل العالم
- خط زمني 622–632م
- أوقات الفجر والظهر والعصر والمغرب والعشاء
- بطاقات معلومات وثقة تاريخية

> هذه إعادة بناء تعليمية مستنيرة تاريخيًا وليست ادعاءً بأن التفاصيل البصرية الدقيقة موثقة بالكامل. لا يعرض المشروع النبي محمد ﷺ أو أي شخصية مرئية ترمز إليه.

## تشغيل محلي

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## البناء

```bash
npm run build
```

يدعم المشروع التصدير الثابت والنشر عبر GitHub Pages.
